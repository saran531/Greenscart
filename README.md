# GREENSCART – Premium Single-Page Corporate Website

A modern, responsive, high-converting corporate website for **GREENSCART** (GRCTS Food Manufacturer Private Limited), based in Madurai, Tamil Nadu.

## Technical Architecture

Built strictly using **standard HTML5, CSS3, and vanilla JavaScript**.
- **No Frameworks**: 0 dependencies (No React, Next.js, Vue, Angular, Bootstrap, or Tailwind CSS).
- **Direct Execution**: Can be launched simply by opening `index.html` directly in any web browser (`file://` or HTTP server).

## How to Run

1. Double click `index.html` to open directly in Microsoft Edge, Google Chrome, Firefox, or Safari.
2. Or serve locally via any HTTP server (e.g. `npx serve .` or `python -m http.server`).
